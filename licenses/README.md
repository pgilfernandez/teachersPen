# License texts and policy

The original desktop LICENSE.md remains the unmodified PolyForm Noncommercial
1.0.0 text.

- MIT.txt applies to the alternative license offered for src/model.ts.
- GPL-2.0-or-later.txt is the GPL version 2 text used with the "or later"
  SPDX grant in the GNOME extension.
- MPL-2.0.txt is included with the unmodified MPL dependency sources.
- policy.json defines reviewed dependency license families.
- third-party/index.json records version-specific upstream/standard-text
  fallbacks for packages that omit a standalone license file.

Canonical GPL and MPL texts were obtained from the SPDX license-list-data
repository:
https://github.com/spdx/license-list-data/tree/main/text

Standard MIT and Apache texts and the preserved upstream texts in third-party/
retain their own terms. The PolyForm license does not apply to these texts.
The source URL for every fallback is recorded in third-party/index.json.
Fallbacks marked standardText are NOT claimed to be original upstream license
files: their notice entries preserve the upstream manifest attribution and
available source copyright lines separately.

See docs/licensing/README.md for packaging, review limitations and commands.
